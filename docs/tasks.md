## 熔断报告

**熔断原因**　方案与数据库设计已同步。当前待评审数据库结构及历史迁移兼容条件，并落实受影响的校方参数。正式任务清单在对应前置条件核定后生成。

**涉及文档**　[spec.md](./spec.md)、[plan.md](./plan.md)、db-design.md（项目内部文档）、[AGENTS.md](../AGENTS.md) 和 [constitution.md](../constitution.md)。

| 阻塞项 | 影响范围 | 需要确认的问题与解除条件 |
|---|---|---|
| B-AUTH　账号与会话持久化 | M1 登录、网关认证及 AC-11 登录审计 | 评审同步后的 `account_credential`、`login_session` 及约束，确认校方凭据初设授权、签名材料、证书和会话配置。 [账号凭据与会话](./plan.md#账号凭据与会话) |
| B-JOB　异步受理与恢复评审 | M1 接入批次、定时及增量更新，M3 预测运行。涉及 AC-01、AC-05 | 评审同步后的执行字段、索引和文件进度，按实际历史数据核定迁移与查询兼容条件。 [异步受理与恢复](./plan.md#异步受理执行与恢复) |
| B-AUDIT　跨服务审计及授权评审 | 招聘归并、技能操作及课程提交、审批。涉及 AC-02、AC-04、AC-08、AC-11 | 评审已同步的两张审计待投递表和 `user_db.audit_event` 接收唯一键，确认校方角色及关键操作复核规则。 [跨服务审计](./plan.md#跨服务审计) |
| B-SUBMIT　课程提交幂等迁移评审 | M4 首次提交与断线重试，涉及 AC-08 | 评审已同步的键摘要、请求摘要及唯一约束，核对已有提交与原有重提规则的兼容性。 [课程提交幂等](./plan.md#课程提交幂等) |
| B-PRED　真实预测验收依据 | M3 的 AC-05，以及依赖真实预测的 SCN-01、SCN-03 完整验收 | 确认真实招聘数据能否覆盖目标范围和评估时段，并明确首个模型、周期、指标、预警及评估口径。报告导出、年度审阅、课程审批和实践资源下载按各自条件独立核对。[规格待确认项](./spec.md#风险假设与待确认项) · [方案前置条件](./plan.md#实施前置与风险裁决) |

**建议裁决**　优先评审已同步的 M1 用户库和数据接入结构。按里程碑核对相应校方条件后恢复生成正式待办清单，沿用 [上一版任务草案](https://github.com/chips-king/industry-talent-demand-forecast/blob/5a05eee4f16d20b8a6cc62ea36ad3e70144f1616/docs/tasks.md) 的需求映射与测试用例。
